# Third-party map asset

`taiwan-location-map.svg` is adapted from **Taiwan location map.svg** by
NordNordWest on Wikimedia Commons.

- Source: https://commons.wikimedia.org/wiki/File:Taiwan_location_map.svg
- License: CC BY-SA 3.0 / GFDL
- Local adaptation: the sea background rectangle was made transparent so the
  map can be drawn over the simulation's dark Canvas background. The coastline,
  island and boundary geometry is otherwise retained from the source SVG.
