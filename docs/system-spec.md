# 系統規格書

## 1. 系統定位

本系統是「戰場情境想定生成、模擬回合推演、決策歷程分析與事後檢討平台」，不是即時作戰決策系統。

第一版的設計原則：

1. 純前端、無後端、無外部服務。
2. 所有兵力與效能均採合成抽象指數。
3. 管理者保有最終裁決權。
4. 評量決策過程，不只評量結果。
5. 公開來源、合成資料與使用者輸入分層管理。

## 2. 使用者角色

### 管理者／白方
- 設定分析目標及難度。
- 生成、修改與發布想定。
- 控制事件、情報揭露及回合結算。
- 檢視決策時間線與事後檢討。

### 藍方使用者
- 分析任務、情報與限制。
- 提出行動方案及資源配置。
- 說明決策理由與風險。

### 紅方使用者
- 從對手角度提出施壓、反制與欺敵行動。
- 檢驗藍方方案的脆弱假設。

### 琥珀方使用者
- 規劃美軍ISR、後勤、網路、外交與有限存在支援。
- 處理政治約束及升級風險。

## 3. 功能模組

### 3.1 想定生成
輸入：
- 分析重點
- 難度
- 回合與時間尺度
- 情報不確定度
- 民事壓力
- 美軍支援程度
- 天候
- 管理者限制

輸出：
- 情境背景
- 分析目標
- 成功條件
- 限制
- 事件排程
- 情報排程
- 初始角色狀態

### 3.2 回合推演
每方每回合提交一份命令包：
- 1項主行動（決定本回合重心）
- 2至4項支援行動
- 每項均記錄行動、區域、資源投入、優先級、執行條件與風險
- 各項資源共用每方每回合35點上限
- 整份命令包的決策理由

結算考量：
- 準備指數
- 持續性
- 指揮品質
- 情報品質
- 資源投入
- 天候
- 事件
- 美軍支援
- 主／支援行動的優先級與資源配置
- 隨機不確定性

### 3.3 情勢視覺化
- 抽象區域格網
- 各方行動標記
- 事件及天候提示
- 狀態指標

### 3.4 分析實驗
攔截資源配置採合成公式：

```text
adjusted_p =
  base_p
  × (0.6 + 0.4 × detection)
  × (0.75 + 0.25 × readiness)
  × (1 - 0.08 × (sea_state - 1))
  × (1 - 0.12 × jamming)

P(at least one success) = 1 - (1 - adjusted_p)^shots
```

限制：
- 僅供比較同一組合成假設下的資源配置。
- 不代表任何真實武器。
- 未建模共同失敗、射擊窗口、同時多目標與指管延遲。

### 3.5 事後檢討
- 回合時間線
- 決策與理由
- 事件及結果
- 最終狀態
- 資源消耗
- 民事風險
- 主要風險提示
- JSON／CSV匯出

## 5. 資料儲存

目前版本：
- 內建資料：JavaScript物件。
- 可攜式資料庫：SQLite與Excel，內容與目前介面設定同步。
- 使用者進度：localStorage。
- 可攜式檔案：JSON。
- 分析資料：CSV。

未來版：
- IndexedDB。
- Firebase／Supabase／校內API。
- 多使用者房間與角色權限。

## 6. 未來LLM介接

建議新增統一介面：

```javascript
async function generateScenarioText(context) {
  // offline provider
  // local-LLM provider
  // approved cloud provider
}
```

必要安全措施：
- 預設僅使用合成資料。
- 不將受限資料傳送至外部模型。
- 管理者核准後才能發布。
- 保留Prompt、模型版本及修改紀錄。
- LLM只產生敘事與分析問題，不直接決定真實武器效能。


## 7. STORM 作戰研究分析實驗室

### 7.1 設計來源與界線
公開資料將 STORM 描述為大型、隨機、戰役層級的資料驅動模擬，用來分析能力、容量、風險與資源方案。本系統只採用下列公開概念：
- 戰役分析流程與可追溯性。
- 五種表徵：C2、Assets、Intelligence、Interactions、Environment。
- 輸入、執行、輸出與後處理。
- 多次獨立重複與結果分布。
- Design of Experiments（DOE）與敏感度分析。

本系統沒有重製正式 STORM 程式、資料格式、武器模型、受限資料或真實情境。

### 7.2 分析流程
1. 使用者點選戰役分析流程，理解系統、能力、計畫、執行與影響。
2. 使用者檢視五種表徵的責任、資料與模型問題。
3. 調整合成C2、ISR、準備度、後勤、機動、環境、壓力與民事暴露。
4. 執行30至500次隨機重複。
5. 比較平均、5–95百分位、90%平均值區間與成功率。
6. 比較四種COA的任務效果、準備度、資源及民事風險。
7. 執行2³因子實驗，估計主效應與二因子／三因子交互作用。
8. 由使用者說明哪些結論來自資料，哪些仍依賴模型假設。

### 7.3 模擬版五種表徵
| 表徵 | 模擬資料 | 主要輸出 |
|---|---|---|
| C2 | 指管品質、命令延遲、備援 | 指揮協調分數 |
| Assets | 準備度、機動、持續性 | 可執行能力與剩餘準備 |
| Intelligence | ISR、可靠度、信心、時效 | 情勢圖像品質 |
| Interactions | 壓力、摩擦、效果與消耗 | 互動效果分數 |
| Environment | 海象、能見度、交通、民事約束 | 環境適應分數 |

### 7.4 統計輸出
- 成功率：符合任務效果、準備度、資源與民事風險四項門檻的比例。
- 平均任務效果。
- 樣本標準差。
- 5%、50%、95%百分位。
- 平均值的90%近似信賴區間。
- 單因子敏感度。
- 2³因子實驗主效應與交互作用。

### 7.5 分析限制
- 係數均為合成值。
- 結果只能比較本模型內的方案。
- 更精確的結果不代表更真實。
- 重複次數增加只能降低抽樣誤差，不能修正錯誤模型。
- 使用者應同時討論驗證、效度、資料品質與倫理限制。
